## json_format_vertexlineルール
### これは何？
マップ作成のためのjsonの座標ルールを記載したもの。
このルールを適用することで、マップの左右端の縦方向が感情する。
目標は長方形の形にするためのルール。

### ルール
- 前提
    - 「左」とは：マップの左端の縦線を示す
    - 「右」とは：マップ右端の縦線を示す
- 入力
    - 入力とは：縦横でどのくらいのマス目にしたいか？をユーザーが入力した数値のこと
- スタート
    - 左：((-1)*入力, 0)
    - 右：（入力, 0）
- 規則
    - 左：スタート起算yが-2されるとxが+1。
    - 右：yが-2されるとxが+1。
- ストップ
    - 左：y軸が(-1)*入力になったら
    - 右：y軸が(-1)*入力になったら
- 例外
    - 左の(x,y)つまり、((-1)*入力, 0)は規則に外れる。規則が適用されるのは、((-1)*入力 + 1, -1)から
- 例）
- 入力が20の場合、jsonは以下のようになる

```
// 左端
      ,{"x":-20,"y":0,"terrain":"Plains"}　 // 左端側　規則対象外
      ,{"x":-19,"y":-1,"terrain":"Plains"}
      ,{"x":-19,"y":-2,"terrain":"Plains"}
      ,{"x":-18,"y":-3,"terrain":"Plains"}
      ,{"x":-18,"y":-4,"terrain":"Plains"}
      ・・・
      ,{"x":-11,"y":-17,"terrain":"Plains"}
     ,{"x":-11,"y":-18,"terrain":"Plains"}
      ,{"x":-10,"y":-19,"terrain":"Plains"}
      {"x":-10,"y":-20,"terrain":"Plains"} // y座標が「(-1)*入力」になった時点で以降を出力しない

// 右端
      ,{"x":20,"y":0,"terrain":"Plains"}
      ,{"x":20,"y":-1,"terrain":"Plains"}
      ,{"x":21,"y":-2,"terrain":"Plains"}
      ,{"x":21,"y":-3,"terrain":"Plains"}
      ,{"x":22,"y":-4,"terrain":"Plains"}
      ,{"x":22,"y":-5,"terrain":"Plains"}
      ・・・
      ,{"x":28,"y":-16,"terrain":"Plains"}
      ,{"x":28,"y":-17,"terrain":"Plains"}
      ,{"x":29,"y":-18,"terrain":"Plains"}
      ,{"x":29,"y":-19,"terrain":"Plains"}
      ,{"x":30,"y":-20,"terrain":"Plains"} // y座標が「(-1)*入力」になった時点で以降を出力しない
```
