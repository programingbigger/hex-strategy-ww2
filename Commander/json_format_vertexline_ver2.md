## json_format_vertexline_ver2 ルール

### 1. コンセプト
このルールは、ヘックス（六角形）座標系において、入力値 $N$ に基づいた「擬似的な長方形（Hex-Grid）」のマップを生成するためのアルゴリズムです。
指定された左端（境界）から右端（境界）までの空間をすべてタイルで埋め、かつ指定されたコンパクトなJSON形式で出力します。

### 2. 生成ロジック（for文の考え方）
マップは $y$ 軸（行）を外側のループ、 $x$ 軸（列）を内側のループとして生成します。

```javascript
// N = 入力数値（例: 50）
for (let y = 0; y >= -N; y--) {
    const xStart = getLeftBoundary(y, N);
    const xEnd = getRightBoundary(y, N);
    
    for (let x = xStart; x <= xEnd; x++) {
        // すべてのタイルを "Plains" で生成
        renderTile(x, y, "Plains");
    }
}
```

### 3. 境界条件（座標計算式）
$y$ 座標の推移に伴い、左右の $x$ 座標の開始・終了位置を以下の規則で決定します。

- **左端（xStart）のルール**
    - $y = 0$ の時： $x = -N$
    - $y < 0$ の時： $x = -N + 1 + \lfloor \frac{-1 - y}{2} floor$
    - （解説：yが-2されるごとにxが+1されるオフセット計算）

- **右端（xEnd）のルール**
    - $x = N + \lfloor \frac{-y}{2} floor$
    - （解説：y軸が負の方向に進むにつれ、xの最大値が緩やかに右にシフトする）

### 4. タイル・プロパティ
- 生成されるすべてのタイルの `terrain` は `"Plains"` とします。
- `{"x": number, "y": number, "terrain": "Plains"}` の形式を維持します。

### 5. JSON出力フォーマット（json-format-compactor準拠）
データの可読性と軽量化のため、以下の「文字列置換」ベースのコンパクト・フォーマットを適用します。

- **タイル・オブジェクトのルール**
    - 1つのタイルオブジェクトを1行で記述する。
    - オブジェクト内のスペース（コロン前後、カンマ前後）をすべて除去する。
- **配列内のセパレータ・ルール**
    - 最初のタイルを除き、行頭にカンマ `,` を配置する。
    - 適切なインデント（スペース6つ）を維持する。

#### 出力例（N=50の場合）
```json
    "tiles": [
      {"x":-50,"y":0,"terrain":"Plains"}
      ,{"x":-49,"y":0,"terrain":"Plains"}
      ,{"x":-48,"y":0,"terrain":"Plains"}
      ...
      ,{"x":-49,"y":-1,"terrain":"Plains"}
      ,{"x":-48,"y":-1,"terrain":"Plains"}
    ]
```

### 6. 品質保証
- 生成後にJSONが構文的に正しい（Valid）ことを確認する。
- `board.tiles` セクション以外（`gameStatus` や `units` など）のインデントや構造は、既存のマップテンプレートを維持し、文字列操作によって surgical（外科手術的）に置換を行う。
