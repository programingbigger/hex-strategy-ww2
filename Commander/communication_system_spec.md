# アストリア軍専用：水晶同期通信網（クリスタル・リンク）概念仕様書

## 1. システムの目的
本システムは、アストリア軍が「大寒波（雪・ブリザード）」という過酷な環境下で、他国を圧倒する機動力と命中精度を維持するための論理基盤である。プレイヤーに「ユニットの配置（陣形）」と「通信網の維持」という新しい戦略的レイヤーを提供する。

## 2. コア・コンセプト：同期と孤立
戦場に展開するアストリア軍の各ユニットは、常に以下のいずれかの論理状態を持つ。

### A. 同期状態 (Synced)
- **判定**: 信号源（ソース）から直接、または中継（リレー）を介して有効な通信信号を受信している。
- **ゲーム的効果**:
  1. **環境耐性**: 天候（雪・ブリザード）による命中率低下ペナルティを100%カットする。
  2. **命中ボーナス**: 通信網によるデータ共有により、基本命中率にプラス補正（例：+10%）を得る。

### B. 孤立状態 (Isolated)
- **判定**: 信号源からの「鎖」が途切れている。
- **ゲーム的効果**:
  1. **環境の影響**: 天候による命中率低下ペナルティを直接受ける。
  2. **連携喪失**: 隣接する味方がいても、同期していなければボーナスは一切得られない。

## 3. ユニットの論理性階層（ロール）

### 1. 信号源 (Signal Source / Hub)
自ら「同期信号」を生成できる特殊ユニット。
- **特性**: ネットワークの「起点」。このユニットが破壊されると、その先のネットワークは全てダウンする。
- **該当**: 通信車（広域）、通信兵（狭域）など。

### 2. 中継点 (Relay Node)
信号を生成できないが、受信した信号を周囲に伝播（コピー）できる一般ユニット。
- **特性**: **自身が「同期状態」の時のみ**、自身の周囲に信号を中継できる。
- **該当**: 戦車、歩兵、装甲車など。

## 4. 通信伝播（リレー）の論理ルール

1. **起点からの距離**: 信号源が持つ「生成半径」内の全ユニットを「同期」とする。
2. **リレーの連鎖**:
   - 同期した一般ユニットは、自身の持つ「中継半径」内に信号を再発信。
   - その半径内にいる別の味方も「同期」となり、さらに先へ中継する。
3. **断絶の条件**: 
   - 信号源からユニットまでの「中継の鎖」が1箇所でも途切れた場合、その先の全ユニットは即座に「孤立状態」にフォールバックする。
   - **重要**: 信号源に繋がっていない一般ユニット同士がいくら隣接していても、同期状態にはならない（0に何を掛けても0であるという論理）。

## 5. 設計上のパラメータ（概念）

- **信号源（通信車）**: 生成半径 7 hex
- **通信兵（特殊中継）**: 生成半径 3 hex / 中継半径 4 hex
- **一般ユニット（戦車・歩兵）**: 中継半径 2 hex

## 6. 実装への指針（他AIへの指示用）
- **判定タイミング**: 毎ターン開始時、およびユニット移動完了時に「起点」からのパス探索を行い、全ユニットの `isSynced` フラグを更新すること。
- **戦闘計算**: 命中率計算関数の直前で `isSynced` を参照し、天候デバフの適用・非適用を分岐させること。
- **UI**: ユニットが同期中か否かを識別できる視覚的なインジケータ（アイコンや範囲表示）が必要。
