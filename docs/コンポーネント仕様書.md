# コンポーネント仕様書

本ドキュメントは、主要なUIコンポーネントの役割、Props、およびStateについて定義します。

## 1. GameBoard

ゲームのメインボードを描画し、ヘックスの配置やユニットの表示を担当します。

- **ファイルパス:** `Commander/src/components/game/GameBoard.tsx`
- **主要なProps:**
  - `units`: 表示するユニットの配列
  - `boardLayout`: マップのタイル情報
  - `onHexClick`: ヘックスがクリックされたときのコールバック関数
  - `selectedUnit`: 選択中のユニット
  - `movableHexes`: 移動可能なヘックスのリスト
- **責務:**
  - マップの地形とグリッドを描画する。
  - ユニットを正しい位置に表示する。
  - ユーザーのヘックスクリックイベントを処理する。
  - 移動可能範囲や攻撃可能範囲をハイライト表示する。

## 2. InformationPanel

選択されたユニットやカーソルが乗っているヘックスの詳細情報を表示するパネルです。

- **ファイルパス:** `Commander/src/components/game/InformationPanel.tsx`
- **主要なProps:**
  - `selectedUnit`: 選択中のユニット情報
  - `hoveredHex`: カーソルが乗っているヘックスの座標
  - `boardLayout`: マップのタイル情報
  - `onAction`: 「待機」や「攻撃」などのアクションボタンが押されたときのコールバック
- **責務:**
  - ユニットのHP、燃料、攻撃力などのステータスを表示する。
  - 地形の情報と防御効果を表示する。
  - ユニットが実行可能なアクション（待機、占領など）のボタンを提供する。

## 3. Hexagon

個々のヘックス（六角形マス）を描画するコンポーネントです。

- **ファイルパス:** `Commander/src/components/game/Hexagon.tsx`
- **主要なProps:**
  - `q`, `r`, `s`: ヘックスの座標
  - `terrain`: 地形タイプ
  - `isMovable`: 移動可能範囲かどうか
  - `isAttackable`: 攻撃可能範囲かどうか
  - `onClick`: クリックされたときのコールバック
- **責務:**
  - 地形に応じた背景画像や色でヘックスを描画する。
  - 移動範囲や攻撃範囲のハイライトを適用する。
  - クリックイベントを親コンポーネントに通知する。

## 4. ArmyUnitSelector

戦闘準備画面で、出撃させるユニットを選択するためのインターフェースです。

- **ファイルパス:** `Commander/src/components/game/ArmyUnitSelector.tsx`
- **主要なProps:**
  - `availableUnits`: 利用可能なユニットのリスト
  - `onUnitSelect`: ユニットが選択されたときのコールバック
  - `deploymentPoints`: 配置に使えるコストの上限
- **責務:**
  - 利用可能なユニットをリスト表示する。
  - ユニットの選択状態を管理する。
  - 配置コストの合計を計算し、上限を超えていないかチェックする。

## 5. BattleScreen

戦闘シーン全体のレイアウトと状態管理を行うコンテナコンポーネントです。

- **ファイルパス:** `Commander/src/screens/BattleScreen.tsx`
- **責務:**
  - `GameBoard`, `InformationPanel` などの主要コンポーネントを統合する。
  - ゲームの全体的な状態（ターン、選択ユニットなど）を管理する。
  - `useGameLogic` フックを呼び出し、ゲームのロジックとUIを接続する。
