# コンポーネント仕様書

本ドキュメントは、主要なUIコンポーネントおよび画面コンポーネントの役割について定義します。

## 1. ゲームプレイコンポーネント (`components/game`)

### GameBoard
ゲームのメインボードを描画し、ヘックスの配置やユニットの表示を担当します。
- **ファイルパス:** `Commander/src/components/game/GameBoard.tsx`

### InformationPanel
選択されたユニットやカーソルが乗っているヘックスの詳細情報を表示するパネルです。
- **ファイルパス:** `Commander/src/components/game/InformationPanel.tsx`

### Hexagon
個々のヘックス（六角形マス）を描画するコンポーネントです。
- **ファイルパス:** `Commander/src/components/game/Hexagon.tsx`

### ArmyUnitSelector
戦闘準備画面で、出撃させるユニットを選択するためのインターフェースです。
- **ファイルパス:** `Commander/src/components/game/ArmyUnitSelector.tsx`

### BattleReportModal
戦闘結果の詳細をモーダルウィンドウで表示します。
- **ファイルパス:** `Commander/src/components/game/BattleReportModal.tsx`

### Header
ゲーム画面の上部に表示されるヘッダーです。タイトルやメニューボタンを配置します。
- **ファイルパス:** `Commander/src/components/game/Header.tsx`

### WeaponInfoPanel
ユニットが装備する武器の情報を表示するパネルです。
- **ファイルパス:** `Commander/src/components/game/WeaponInfoPanel.tsx`

### WeaponSelectorModal
攻撃時に使用する武器を選択するためのモーダルです。
- **ファイルパス:** `Commander/src/components/game/WeaponSelectorModal.tsx`

## 2. 画面コンポーネント (`screens`)

### TitleScreen
ゲームのタイトル画面です。ゲーム開始や設定への導線となります。
- **ファイルパス:** `Commander/src/screens/TitleScreen.tsx`

### HomeScreen
ゲームのメインメニュー画面です。シナリオ選択など、各種モードへのハブとなります。
- **ファイルパス:** `Commander/src/screens/HomeScreen.tsx`

### ScenarioSelectScreen
プレイするシナリオを選択する画面です。
- **ファイルパス:** `Commander/src/screens/ScenarioSelectScreen.tsx`

### BattlePrepScreen
戦闘開始前の準備画面です。部隊の編成などを行います。
- **ファイルパス:** `Commander/src/screens/BattlePrepScreen.tsx`

### UnitDeploymentScreen
マップ上にユニットを配置する画面です。
- **ファイルパス:** `Commander/src/screens/UnitDeploymentScreen.tsx`

### BattleScreen
戦闘シーン全体のレイアウトと状態管理を行うコンテナコンポーネントです。
- **ファイルパス:** `Commander/src/screens/BattleScreen.tsx`

### ResultScreen
戦闘終了後のリザルト（結果）を表示する画面です。
- **ファイルパス:** `Commander/src/screens/ResultScreen.tsx`
