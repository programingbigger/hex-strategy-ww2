# データモデル仕様書

本ドキュメントは、ゲーム内で使用される主要なデータ構造について定義します。

## 1. ユニット (Unit)

ユニットは、プレイヤーが操作する駒を表します。

- **主要なプロパティ:**
  - `id`: ユニットの一意なID (string)
  - `type`: ユニットの種類 (例: "Rifle Infantry", "Light Tank") (string)
  - `name`: ユニットの固有名称 (オプショナル) (string)
  - `team`: 所属するチーム (例: "Blue", "Red") (string)
  - `x`, `y`: マップ上の座標 (number)
  - `hp`: 現在のヒットポイント (number)
  - `maxHp`: 最大ヒットポイント (number)
  - `fuel`: 現在の燃料 (number)
  - `maxFuel`: 最大燃料 (number)
  - `ammo`: 現在の弾薬 (number)
  - `maxAmmo`: 最大弾薬 (number)
  - `attack`: 攻撃力 (number)
  - `defense`: 防御力 (number)
  - `movement`: 移動力 (number)
  - `attackRange`: 攻撃範囲 (min, max) (object)
  - `unitClass`: ユニットクラス (例: "Infantry", "Armor") (string)
  - `moved`: 移動済みかどうかのフラグ (boolean)
  - `attacked`: 攻撃済みかどうかのフラグ (boolean)
  - `xp`: 経験値 (number)
  - `level`: レベル (number)
  - `weapons`: 装備している武器のリスト ([Weapon])

- **関連ファイル:**
  - `Commander/src/types/index.ts`
  - `Commander/src/data/units.ts`
  - `Commander/src/data/armyOrganization.json`

## 2. タイル (Tile)

タイルは、ゲームボードを構成する個々のヘックス（マス）を表します。

- **主要なプロパティ:**
  - `x`, `y`: マップ上の座標 (number)
  - `terrain`: 地形タイプ (例: "Plains", "Forest", "City") (string)
  - `owner`: このタイルを所有しているチーム (例: "Blue", "Red", null) (string | null)
  - `hp`: 建物などのHP (オプショナル) (number)
  - `maxHp`: 建物などの最大HP (オプショナル) (number)

- **関連ファイル:**
  - `Commander/src/types/index.ts`
  - `Commander/public/data/maps/*.json`

## 3. 武器 (Weapon)

武器は、ユニットが装備し、戦闘に使用するものです。

- **主要なプロパティ:**
  - `id`: 武器の一意なID (string)
  - `name`: 武器の名称 (例: "75mm Cannon") (string)
  - `type`: 武器の種類 (例: "Anti-Tank", "Artillery") (string)
  - `ammo`: 弾薬数 (number)
  - `maxAmmo`: 最大弾薬数 (number)
  - `effectiveness`: 各ユニットクラスに対する有効性 (object)
    - (例: `{ "Infantry": 1.2, "Armor": 0.8 }`)

- **関連ファイル:**
  - `Commander/src/types/index.ts`
  - `Commander/src/utils/weapons.ts`

## 4. マップ (Map)

マップは、ゲームの舞台となるボード全体の情報を持ちます。

- **主要なプロパティ:**
  - `width`: マップの幅 (number)
  - `height`: マップの高さ (number)
  - `tiles`: タイルの配列 ([Tile[]])
  - `name`: マップ名 (string)
  - `description`: マップの説明 (string)
  - `victoryConditions`: 勝利条件 (object)

- **関連ファイル:**
  - `Commander/src/types/index.ts`
  - `Commander/public/data/maps/*.json`
