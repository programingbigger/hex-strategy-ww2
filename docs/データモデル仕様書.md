# データモデル仕様書

本ドキュメントは、ゲーム内で使用される主要なデータ構造について定義します。これは `Commander/src/types/index.ts` の内容に基づいています。

## 1. 基本型 (Basic Types)

- `Team`: チーム ("Blue" | "Red")
- `Faction`: 勢力 ("Blue" | "Red")
- `MilitaryBranch`: 軍種 ("陸" | "海" | "空")
- `UnitCategory`: ユニットカテゴリ (歩兵、機甲、砲兵など)
- `UnitType`: ユニット種別 (Infantry, Tankなど)
- `UnitClass`: ユニットクラス (Infantry, Vehicle)
- `WeatherType`: 天候 ("Clear" | "Rain" | "HeavyRain" | "Cloudy")
- `TerrainType`: 地形 (平野, 森林, 山, 川など)

## 2. 主要データ構造

### ユニット (Unit)

プレイヤーが操作する駒を表します。

- **主要プロパティ:**
  - `id`: ユニットの一意なID (string)
  - `type`: ユニット種別 (UnitType)
  - `team`: 所属チーム (Team)
  - `faction`: 所属勢力 (Faction)
  - `branch`: 所属軍種 (MilitaryBranch)
  - `category`: ユニットカテゴリ (UnitCategory)
  - `name`: 表示名 (string)
  - `hp`, `maxHp`: ヒットポイント (number)
  - `fuel`, `maxFuel`: 燃料 (number)
  - `movement`: 移動力 (number)
  - `defense`: 防御力 (number)
  - `x`, `y`: マップ上の座標 (number)
  - `moved`, `attacked`: 行動済みフラグ (boolean)
  - `canCounterAttack`: 反撃可能か (boolean)
  - `unitClass`: ユニットクラス (UnitClass)
  - `weapons`: 装備している武器のリスト ([Weapon])
  - `attack`, `attackRange`: (Legacy) 旧式の攻撃力と範囲

### タイル (Tile)

ゲームボードを構成する個々のヘックス（マス）を表します。

- **主要プロパティ:**
  - `x`, `y`: マップ上の座標 (number)
  - `terrain`: 地形タイプ (TerrainType)
  - `owner`: 所有チーム (Team | undefined)
  - `hp`, `maxHp`: 建物の耐久値 (number | undefined)

### 武器 (Weapon)

ユニットが装備する武器です。

- **主要プロパティ:**
  - `id`: 武器の一意なID (string)
  - `name`: 武器名 (string)
  - `type`: 武器種別 (WeaponType)
  - `ammunition`, `maxAmmunition`: 弾薬数 (number)
  - `range`: 射程距離 ({ min: number; max: number })
  - `attack`: 攻撃力 (number)
  - `effectiveness`: ユニットクラスに対する有効性 ({ [key in UnitClass]?: number })

### マップデータ (MapData)

シナリオの全ての情報を含みます。

- **主要プロパティ:**
  - `gameStatus`: ゲームの状態 (ターン、天候、勝利条件など)
  - `board`: タイルの配列 ({ tiles: Tile[] })
  - `units`: 初期配置ユニットの配列 ([Unit[]])
  - `deploymentCenter`: 出撃拠点 ({ q: number; r: number } | undefined)

## 3. ゲーム状態管理 (Game State)

### GameState

ゲーム全体の現在の状態を管理します。

- **主要プロパティ:**
  - `currentScreen`: 現在の画面 (GameScreen)
  - `selectedMap`: 選択中のマップ (GameMap)
  - `units`: 現在の全ユニット ([Unit[]])
  - `board`: 現在のボードレイアウト (BoardLayout)
  - `activeTeam`: 現在行動中のチーム (Team)
  - `turn`: 現在のターン数 (number)
  - `winner`: 勝者 (Team | undefined)

### BattleReport

戦闘結果の詳細なレポートです。

- **主要プロパティ:**
  - `attacker`, `defender`: 攻撃側と防御側のユニット (Unit)
  - `damage`, `counterDamage`: 与えたダメージ (number)
  - `report`: 戦闘結果のテキスト (string)
  - `weaponUsed`, `counterWeaponUsed`: 使用された武器 (Weapon)

## 4. 軍隊編成 (Army Organization)

`armyOrganization.json` に対応するデータ構造です。

### ArmyOrganization

勢力ごとの軍隊の編成情報を定義します。

- **主要プロパティ:**
  - `metadata`: メタデータ (バージョン情報など)
  - `factions`: 勢力ごとのデータ (Record<Faction, FactionData>)
  - `commandStructure`: 指揮系統 (CommandStructure)

### ArmyUnitTemplate

ユニットのテンプレート（雛形）です。

- **主要プロパティ:**
  - `id`, `name`, `type`, `faction`, `branch`, `category`: ユニットの基本情報
  - `stats`: ユニットの基本ステータス (UnitStats)
  - `weapons`: 標準装備の武器 ([Weapon[]])
