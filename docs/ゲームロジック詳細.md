# ゲームロジック詳細

本ドキュメントは、ゲームのコアとなるロジック、特に `useGameLogic` フック内で処理される内容について詳述します。

- **関連ファイル:** `Commander/src/hooks/useGameLogic.ts`

## 1. ゲームの進行管理 (Turn Management)

- ゲームはターン制で進行します。
- `turn` stateで現在のターン数と、どちらのチームのターンか (`currentPlayer`) を管理します。
- `End Turn` ボタンが押されると、次のプレイヤーにターンが移り、ターンカウンターが更新されます。
- ターン開始時、全ユニットの `moved` と `attacked` フラグが `false` にリセットされます。

## 2. ユニットの操作 (Unit Actions)

### a. 移動 (Movement)

1.  プレイヤーが自軍のユニットをクリックすると、そのユニットが `selectedUnit` として設定されます。
2.  ユニットの移動力と地形の移動コストを考慮して、移動可能な範囲 (`movableHexes`) が計算されます。
    - 川や山などの地形は、より多くの移動力を消費します。
    - 敵ユニットがいるヘックスは通行不可能です（ZOC: Zone of Control の影響も考慮）。
3.  プレイヤーが移動可能なヘックスをクリックすると、ユニットの座標が更新され、`moved` フラグが `true` に設定されます。
4.  移動後は、攻撃などの次のアクションを選択できます。

### b. 戦闘 (Combat)

1.  移動後のユニットが、攻撃範囲内にいる敵ユニットを選択すると、戦闘が開始されます。
2.  戦闘結果は、攻撃側の `attack` 値、防御側の `defense` 値、地形効果、ユニットの相性、HP状況などを元に計算されます。
    - 例: `(攻撃力 - 防御力) * 地形補正 * 乱数`
3.  計算されたダメージが双方のユニットに適用され、HPが更新されます。
4.  HPが0以下になったユニットはマップから取り除かれます。
5.  戦闘後、攻撃したユニットの `attacked` フラグが `true` に設定されます。

### c. 占領 (Capture)

1.  歩兵ユニット (`unitClass: 'Infantry'`) が、敵が所有する都市や施設（`City`, `Airport`など）のタイルに移動し、待機すると占領が開始されます。
2.  占領には数ターンかかる場合があり、その間ユニットは無防備になります。
3.  占領が完了すると、タイルの `owner` が占領したプレイヤーのチームに変更されます。

## 3. 勝利条件 (Victory Conditions)

- `victory-conditions.md` にも記載されている通り、勝利条件はシナリオによって異なります。
- 主な勝利条件は以下の通りです。
  1.  **敵の首都占領:** 指定された敵の首都を占領する。
  2.  **敵ユニットの全滅:** 敵の全てのユニットを撃破する。
  3.  **規定ターン防衛:** 指定されたターン数、自軍の首都を防衛しきる。
- `useGameLogic` は毎ターン終了時に勝利条件が満たされているかをチェックし、満たされていればゲームを終了させ、リザルト画面に遷移します。

## 4. 補給と回復 (Supply and Recovery)

- ユニットは、自軍が所有する都市や空港などの補給拠点にターンを開始すると、HPと燃料が一定量回復します。
- 回復量は拠点の種類によって異なります。
