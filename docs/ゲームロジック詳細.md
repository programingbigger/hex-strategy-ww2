# ゲームロジック詳細

本ドキュメントは、ゲームのコアとなるロジック、特に `Commander/src/hooks/useGameLogic.ts` フック内で処理される内容について詳述します。

## 1. 状態管理 (State Management)

`useGameLogic` フックは `useState` を用いてゲームの全ての状態を管理します。主要な状態は以下の通りです。

- `gameState`: ゲームの状況 ('playing' | 'gameOver')
- `turn`: 現在のターン数
- `activeTeam`: 行動中のチーム ('Blue' | 'Red')
- `boardLayout`: マップのタイル情報
- `units`: 全てのユニットの配列
- `selectedUnitId`: 選択中のユニットID
- `battleReport`: 最新の戦闘結果
- `victoryResult`: ゲームの勝利条件と結果
- `history`: アクションの履歴（Undo機能用）
- `weaponSelectionState`: 武器選択モーダルの状態

## 2. ゲームのライフサイクル

### a. ゲームの読み込み (`loadGame`)

- `MapData` オブジェクトからマップ、ユニット、ゲーム状態（ターン、天候、勝利条件など）を読み込み、stateを初期化します。

### b. ターン終了 (`handleEndTurn`)

1.  **プレイヤー交代:** `activeTeam` を次のプレイヤーに切り替えます。
2.  **ユニット状態リセット:** 全ユニットの `moved`, `attacked` フラグをリセットします。
3.  **補給と回復:** 次のプレイヤーのユニットに対して、所有する都市タイル上でのHPと燃料・弾薬の補給処理を行います。
4.  **ターン数更新:** プレイヤーがBlueに戻るタイミングでターン数をインクリメントします。
5.  **天候変動:** ターン更新時に天候がランダムに変動し、継続的な雨によって地形が「ぬかるみ」に変わることがあります。
6.  **勝利条件チェック:** `checkWinCondition` を呼び出します。
7.  **ターン制限チェック:** 設定されたターン制限を超えていた場合、防衛側の勝利となります。

## 3. ユニットのアクション (`handleHexClick`)

ヘックスがクリックされた際の主要なロジックです。

1.  **ユニット選択:** 自軍の未行動ユニットをクリックすると、そのユニットが選択状態になります。
2.  **移動:** 移動可能範囲内の空のヘックスをクリックすると、ユニットが移動します。燃料が消費され、`moved` フラグが `true` になります。
3.  **攻撃:** 攻撃可能範囲内の敵ユニットをクリックすると、戦闘が開始されます。
    - **武器選択:** 攻撃ユニットが複数の武器を持つ場合、`weaponSelectionState` が更新され、武器選択モーダルが開きます。
    - **戦闘処理:** `handleAttackWithWeapon` が呼び出されます。

## 4. 戦闘ロジック (`handleAttackWithWeapon`)

1.  **ダメージ計算:** 選択された武器の攻撃力、ユニット相性、地形効果を元にダメージを計算します。
2.  **弾薬消費:** 攻撃側のユニットの武器の弾薬を消費します。
3.  **HP更新:** `safeUpdateUnitHP` を通じて、双方のユニットのHPを安全に更新します。HPが0になったユニットは盤面から取り除かれます。
4.  **反撃:** 防御側ユニットが反撃可能な場合、射程内にいれば自動で最適な武器を選択し反撃します。
5.  **戦闘レポート:** `battleReport` stateを更新し、戦闘結果を表示します。
6.  **状態更新:** 攻撃したユニットは `attacked` フラグが `true` になります。

## 5. その他のアクション (`handleAction`)

- **待機 (wait):** ユニットの行動を終了させます。
- **占領 (capture):** 歩兵ユニットが敵の都市タイル上で実行すると、都市のHPを減少させます。HPが0になると自軍の都市になります。
- **元に戻す (undo):** `history` stateを利用して、直前のアクションを取り消し、ユニットの状態を一手前に戻します。

## 6. 勝利条件 (`checkWinCondition`)

ターン終了時に以下の優先順位で勝利条件をチェックします。

1.  **敵ユニットの全滅**
2.  **敵の首都の完全占領**
3.  **全ての占領可能都市の確保**

いずれかの条件が満たされると、`gameState` が 'gameOver' になり、`victoryResult` が設定されます。
