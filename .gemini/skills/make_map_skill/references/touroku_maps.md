# touroku_maps.md
マップの名前を受け取ったら、以下のフォーマットに沿って、Commander/src/data/maps.tsへ登録する。なお、以下のフォーマットはjson形式でそれ以外の部分は、Commander/src/data/maps.tsは変更しない。以下フォーマットを追加するだけ。

以下、受け取ったマップの名前を{map_name}とする

## フォーマット
json形式で以下のような形で登録する
{
    id: "map_name", // ここが登録された{}.jsonの{}と同じでなくてはいけない
    name:: "", // 自由記述（日本語のカタカナで10文字以内。いかにも世界にありそうな地名を記載する）
    description: "" // 自由記述（100〜250文字以内で日本語。ストーリーっぽく。攻める理由などを記載）
}
