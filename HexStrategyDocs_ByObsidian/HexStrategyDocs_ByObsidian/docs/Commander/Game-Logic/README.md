# Game-Logic - ゲームロジック

戦闘システムと状態管理の中核を担うロジック群です。地形システムを含む包括的なゲームメカニクスを提供します。

## モジュール一覧

### [[useGameLogic]] - メインゲームロジック
戦闘計算、ターン管理、AI処理の統合管理フック。地形効果を含む全ゲームメカニクスを処理します。

### [[constants]] - ゲームバランス設定  
ユニット能力、地形効果、戦闘ルールの定数定義。17種類の地形タイプとその詳細効果を管理します。

### [[terrain-types]] - 地形タイプ詳細仕様
全地形タイプの防御・攻撃ボーナス、兵種別移動コストを定義した参照テーブル。戦術計画の基礎資料として活用されます。

## 地形システム統合

### 地形効果の適用範囲
- **移動システム**: 兵種別の地形移動コスト
- **戦闘システム**: 地形による攻撃・防御修正
- **補給システム**: 都市・港・飛行場での回復効果
- **制限システム**: 車両の河川・山岳通行不可

### 戦術的重要地形
- **防御拠点**: 山岳(+3)、要塞(+3)、首都(+3)
- **攻撃拠点**: 山岳(+2攻撃)、首都(+1攻撃)、飛行場(+1攻撃)
- **補給拠点**: 都市、首都、港、飛行場
- **機動路**: 道路、平原（低移動コスト）

## 依存関係

```
useGameLogic → constants (TERRAIN_STATS)
useGameLogic → terrain-types (地形仕様参照)
useGameLogic → types-index (TerrainType定義)
constants → terrain-types (地形データ同期)
```
