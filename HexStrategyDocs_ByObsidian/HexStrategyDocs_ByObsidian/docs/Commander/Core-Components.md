# Core-Components

This document provides an overview of the core game components in `Commander/src/components/game`.

## File Index

- `ArmyUnitSelector.tsx`: A modal for selecting army units.
- `BattleLogPanel.tsx`: Displays a log of battle events.
- `BattleReportModal.tsx`: A modal to show the results of a battle.
- `EndTurnConfirmModal.tsx`: A modal to confirm ending the current turn.
- `EngineerActionConfirmModal.tsx`: A modal to confirm engineer actions like building or destroying bridges.
- `GameBoard.tsx`: The main game board where hexes and units are rendered.
- `Header.tsx`: The header component that displays turn, team, and weather information.
- `Hexagon.tsx`: Renders a single hexagon tile on the game board.
- `InformationPanel.tsx`: Displays information about the selected unit or hovered hex.
- `ProductionModal.tsx`: A modal for producing new units.
- `RainEffect.tsx`: Renders a rain effect on the screen based on the weather.
- `ReinforcementNotificationModal.tsx`: A modal to notify the player about enemy reinforcements.
- `ReinforcementPreview.tsx`: Shows a preview of upcoming enemy reinforcements.
- `SelectedUnitPanel.tsx`: Displays detailed information and actions for the selected unit.
- `ShortcutsPanel.tsx`: A panel that displays available keyboard shortcuts.
- `TransportActionConfirmModal.tsx`: A modal to confirm transport actions like loading or unloading units.
- `TurnChangeModal.tsx`: A modal that appears when the turn changes.
- `UnitSelectionModal.tsx`: A modal for selecting a unit from a transport.
- `VictoryModal.tsx`: A modal that is displayed when a player wins or loses the game.
- `WeaponInfoPanel.tsx`: Displays information about a unit's weapons.
- `WeaponSelectorModal.tsx`: A modal for selecting a weapon to use in an attack.
