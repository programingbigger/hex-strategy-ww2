# Screens

This document provides an overview of the screens in `Commander/src/screens`.

## File Index

- `BattlePrepScreen.tsx`: The screen where the player prepares for battle by selecting units.
- `BattleScreen.tsx`: The main screen where the battle takes place.
- `HomeScreen.tsx`: The home screen of the application, where the player can select a game mode.
- `ResultScreen.tsx`: The screen that displays the results of the battle.
- `ScenarioSelectScreen.tsx`: The screen where the player can select a scenario or map to play.
- `TitleScreen.tsx`: The title screen of the application.
- `UnitDeploymentScreen.tsx`: The screen where the player deploys their units on the map before the battle starts.
