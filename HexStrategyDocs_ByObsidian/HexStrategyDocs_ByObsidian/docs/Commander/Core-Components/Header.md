# Header

`Header.tsx`は、ゲーム画面上部に表示されるヘッダーコンポーネントです。現在のターン数、アクティブなチーム、天気、各チームのユニット数などの重要なゲーム情報を表示します。

## 概要

このコンポーネントは、プレイヤーがゲームの全体的な状況を一目で把握できるようにするための情報を提供します。セーブやロード機能へのアクセスポイントも提供します。

## Props

| Prop         | Type                  | Description                                    |
| ------------ | --------------------- | ---------------------------------------------- |
| `turn`       | `number`              | 現在のターン数。                               |
| `activeTeam` | `Team`                | 現在行動中のチーム（'Blue' または 'Red'）。     |
| `weather`    | `WeatherType`         | 現在の天気（'Clear', 'Rain', 'Storm'）。   |
| `blueUnits`  | `number`              | 青チームの残存ユニット数。                     |
| `redUnits`   | `number`              | 赤チームの残存ユニット数。                     |
| `onSave`     | `() => void` (optional) | セーブボタンがクリックされたときのコールバック。 |
| `onLoad`     | `() => void` (optional) | ロードボタンがクリックされたときのコールバック。 |

## 表示要素

- **ターン数**: `Turn {turn}` の形式で表示。
- **アクティブチーム**: 現在のチーム名（例: "Blue Team's Turn"）をチームカラーの背景で表示。
- **天気**: 天気の種類に応じた絵文字（☀️, 🌧️, ⛈️）と共に天候名を表示。
- **ユニット数**: 各チームの残存ユニット数をそれぞれのチームカラーで表示。
- **セーブ/ロードボタン**: `onSave` と `onLoad` プロパティが渡された場合にのみ表示される。
