# BattleLogPanel

`BattleLogPanel.tsx`は、ゲーム中に発生した戦闘イベントを時系列で表示するためのログパネルコンポーネントです。

## 概要

このパネルは画面下部に表示され、どのユニットがどのユニットを攻撃し、どのような結果になったかの詳細な戦闘記録を提供します。新しいログが追加されると、自動的に最新のログまでスクロールする機能も備えています。

## Props

| Prop          | Type                                          | Description                                    |
| ------------- | --------------------------------------------- | ---------------------------------------------- |
| `battleLog`   | `BattleLogState`                              | 表示する戦闘ログのエントリと状態を含むオブジェクト。 |
| `currentTurn` | `number`                                      | 現在のターン数。ヘッダーに表示されます。         |
| `currentPhase`| `'Player Phase' \| 'Enemy Phase'`             | 現在のフェーズ。ヘッダーに表示されます。         |

## 表示内容

### ヘッダー
- **タイトル**: "BATTLE LOG"
- **現在の状況**: `[ Turn: {currentTurn} / {currentPhase} ]`
- **スクロールボタン**: クリックするとログの最下部にスクロールします。

### ログエントリ

各戦闘イベントは、以下の詳細情報を含んで表示されます。

- **主要戦闘ライン**: 誰が誰を、どの場所（地形、座標）で攻撃したかを表示。
  - `[チームフラグ] 攻撃ユニット名 (HP: 攻撃前 → 攻撃後) attacks [チームフラグ] 防御ユニット名 (HP: 防御前 → 防御後) at Hex(x,y) in 地形名 (+防御ボーナス)`
- **兵器詳細ライン**: 攻撃側が使用した兵器、与えたダメージ、受けたダメージ、ユニットが破壊されたかどうかを表示。
- **反撃ライン** (`counterAttack`が存在する場合): 防御側が反撃した場合、その詳細を表示。

## スタイルとフォーマット

- チームフラグ（例: `[SOV]`, `[GER]`）とチームカラーを使用して、視覚的にどちらの軍のユニットか分かりやすくしています。
- 地形効果による防御ボーナスも表示されます。
- ログがない場合は、「No battle events yet.」というメッセージが表示されます。
