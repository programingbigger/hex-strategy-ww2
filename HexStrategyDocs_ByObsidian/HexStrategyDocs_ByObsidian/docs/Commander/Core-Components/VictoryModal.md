# VictoryModal

`VictoryModal.tsx`は、戦闘の勝利・敗北条件が満たされたときに表示されるモーダルウィンドウです。

## 概要

このコンポーネントは、どちらかの軍が降伏または勝利した際に、その結果をプレイヤーに通知します。モーダル内には状況に応じたメッセージと、タイトル画面に戻るためのボタンが表示されます。

## Props

| Prop           | Type                  | Description                                      |
| -------------- | --------------------- | ------------------------------------------------ |
| `isOpen`       | `boolean`             | モーダルが表示されているかどうかを制御します。   |
| `defeatedArmy` | `string` (optional)   | 降伏した軍の名前。                               |
| `winnerArmy`   | `string` (optional)   | 勝利した軍の名前。                               |
| `onClose`      | `() => void`          | 「タイトルへ戻る」ボタンがクリックされたときのコールバック。 |

## 表示ロジック

- `isOpen`が`true`の場合にのみモーダルが表示されます。
- `winnerArmy`が存在する場合、タイトルは「🏆 戦闘結果」となり、勝利メッセージが表示されます。
- `winnerArmy`が存在しない場合（例：引き分けや特殊なシナリオ）、タイトルは「⚔️ 戦況報告」となります。
- 表示されるメッセージは`getMessage`関数によって動的に生成されます。（例：「Red軍が降伏しました。Blue軍が勝利です。」）
- ボタンをクリックすると`onClose`コールバックが実行され、通常はタイトル画面へ遷移します。
