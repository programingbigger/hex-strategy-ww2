# WeaponInfoPanel - 武器情報表示パネル

## 概要
選択されたユニットの武装状況を詳細表示するUIコンポーネントです。プレイヤーの戦術判断に必要な武器情報を分かりやすく提示し、弾薬管理と戦略的思考を支援します。

## ファイル場所
`/Commander/src/components/game/WeaponInfoPanel.tsx`

## 主要機能

### 武装状況の可視化
- **武器リスト表示**: ユニットが搭載する全武器の一覧表示
- **弾薬状況表示**: 各武器の残弾数/最大弾薬数の明確な表示
- **視覚的弾薬インジケーター**: プログレスバーによる弾薬残量の直感的表示
- **武器状態管理**: メイン武器の識別と弾薬切れ警告

### レガシーシステム対応
- **互換性維持**: 旧システムのユニット（基本武装のみ）への対応
- **統一UI**: 新旧システム両方に対して一貫したUI表示
- **段階的移行**: システム更新中の混在状態に対する安定動作

## 技術実装詳細

### 武器システム判定

const hasWeapons = unit.weapons && Array.isArray(unit.weapons) && unit.weapons.length > 0;

// 新システム: weapons配列を持つユニット
// レガシー: attack, attackRangeを直接持つユニット

### 弾薬インジケーターロジック
```typescript
const AmmoIndicator = ({ ammunition, maxAmmunition }) => {
  const percentage = (ammunition / maxAmmunition) * 100;
  const color = percentage > 30 ? '#4CAF50' : percentage > 0 ? '#FF9800' : '#f44336';
  
  return (
    <div className="ammo-bar">
      <div style={{ width: `${percentage}%`, backgroundColor: color }} />
    </div>
  );
};
```

### 状態別表示制御
```typescript
// メイン武器識別
{index === 0 && <span>(メイン)</span>}

// 弾薬切れ表示
color: weapon.ammunition > 0 ? '#4CAF50' : '#888'

// 警告メッセージ
{hasWeapons && unit.weapons\!.every(w => w.ammunition === 0) && (
  <div className="no-ammo-warning">⚠️ 全ての弾薬が尽きています</div>
)}
```

## スタイリング仕様

### パネルデザイン
- **背景**: ダークテーマ（#2a2a2a）
- **境界**: グレー境界線（#444）
- **テキスト**: 白文字（#fff）、ゴールドヘッダー（#ffd700）

### 弾薬インジケーター
- **高残量**: 緑色（#4CAF50） - 30%以上
- **中残量**: オレンジ色（#FF9800） - 1-29%
- **空**: 赤色（#f44336） - 0%
- **無限**: 緑色表示

### 状態表示
- **有効武器**: 緑色文字（#4CAF50）
- **弾薬切れ**: グレー文字（#888）
- **警告**: 赤背景（#4a1a1a）、赤境界（#f44336）

## 表示項目一覧

### 武器情報
- **武器名**: 明確な武器識別名

- **弾薬警告**: 全武器弾薬切れ時の警告メッセージ
