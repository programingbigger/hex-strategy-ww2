# SelectedUnitPanel

`SelectedUnitPanel.tsx`は、ゲームボード上で選択されたユニットの詳細情報を表示し、関連するアクションボタンを提供するUIコンポーネントです。

## 概要

このパネルは、選択されたユニットが存在する場合にそのユニットのステータス（HP, 燃料, 経験値）、戦闘能力、位置、状態などを表示します。また、ユニットが実行可能なアクション（待機, 行動取消, 占領など）のボタンを提供します。工兵ユニットが選択された場合は、特別な建設・破壊アクションも表示されます。

パネル下部には、キーボードショートカットの情報が常に表示されます。

## Props

| Prop               | Type                                                                                                                                                           | Description                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `selectedUnit`     | `Unit` (optional)                                                                                                                                              | 選択されているユニットオブジェクト。                                        |
| `selectedUnitTile` | `Tile` or `null`                                                                                                                                               | 選択されているユニットがいるタイルオブジェクト。                            |
| `onAction`         | `(action: 'wait' | 'undo' | 'capture' | 'enhance_city' | 'build_bridge' | 'build_fortress' | 'destroy_fortress' | 'destroy_bridge', materialAmount?: number) => void` | ユーザーがアクションボタンをクリックしたときに呼び出されるコールバック関数。 |
| `boardLayout`      | `Map<string, Tile>`                                                                                                                                            | 現在のゲームボードのレイアウト情報。                                        |

## 主要機能

### 1. ユニット情報の表示

- **基本情報**: ユニット名、チーム、所属（兵科・カテゴリ）。
- **ステータスバー**: HP, 燃料, 経験値をプログレスバーで表示。
- **戦闘ステータス**: 攻撃力, 防御力, 移動力, 射程。
- **位置と状態**: 座標 (x, y) と、現在の状態（Ready, Moved, Attacked, Done）。
- **兵装情報**: `WeaponInfoPanel`コンポーネントを呼び出して表示。

### 2. 標準アクション

- **Wait**: ユニットの行動を終了します。
- **Undo**: ユニットが移動後、未攻撃の場合に限り、移動を取り消すことができます。
- **Capture**: 歩兵ユニットが占領可能な地形（都市、首都、空港、港）におり、その地形が自軍のものでない場合に表示されます。

### 3. 工兵アクション

選択されたユニットが工兵 (`type === 'Engineer'`) の場合に表示される特殊アクションです。各アクションは特定の地形条件と資材（`material`）を必要とします。

- **増築 (Enhance City)**: 自軍の都市系地形にいる場合に可能。資材を1消費。
- **架橋 (Build Bridge)**: 川(River)地形に隣接している場合に可能。資材を2消費。
- **要塞化 (Build Fortress)**: 平原(Plains)地形にいる場合に可能。資材を1消費。
- **要塞無力化 (Destroy Fortress)**: 要塞(Fortress)地形にいる場合に可能。資材を2消費。
- **橋破壊 (Destroy Bridge)**: 橋(Bridge)地形に隣接している場合に可能。資材を2消費。

### 4. ショートカット表示

- **ターン終了 (Cmd+E)**
- **選択解除 (Esc)**
- **選択ユニットへ中央揃え (Space)**
