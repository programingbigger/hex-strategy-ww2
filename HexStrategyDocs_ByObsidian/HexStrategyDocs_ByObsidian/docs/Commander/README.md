# Commander - ヘックス戦略ゲーム

## 概要
Commander は TypeScript/React で構築された第二次世界大戦をテーマとしたヘックス戦略ゲームです。プレイヤーは青軍として赤軍と戦い、地形を活用した戦術で都市を占領し、戦略的な勝利を目指します。

## アーキテクチャ概要
- **技術スタック**: React 18.2.0, TypeScript 4.9.5
- **状態管理**: React Hooks ベース
- **ゲームフロー**: タイトル → ホーム → シナリオ選択 → 戦闘準備 → ユニット配置 → 戦闘 → 結果

## ゲームシステムの特徴

### 地形戦術システム
- **17種類の地形**: 平原、森林、山岳、河川、道路、橋梁、都市、泥濘、海洋、首都、飛行場、生垣地、雪原、砂漠、岩礁、要塞、港
- **兵種別移動制限**: 歩兵は全地形対応、車両は河川・山岳通行不可
- **戦闘修正**: 地形による攻撃・防御ボーナス（山岳+3防御+2攻撃、要塞+3防御+1攻撃など）
- **戦術的価値**: 高所からの攻撃優位性、要塞での防御戦術、道路での高速機動

### 補給システム
- **都市補給**: 占領都市でのHP・燃料回復
- **燃料管理**: 移動による燃料消費と補給の戦略的重要性
- **戦略拠点**: 首都・港・飛行場の特別効果

### 武器システム
- **派閥別武装**: 青軍・赤軍それぞれ専用の武器体系
- **射程管理**: ユニット・武器ごとの攻撃射程
- **弾薬管理**: 武器ごとの弾薬制限

1. **地形読み**: プレイヤーは地形の戦術的価値を理解し、適切なポジショニングが重要

4. **機動戦術**: 道路網を活用した高速展開と河川・山岳による防御線構築
