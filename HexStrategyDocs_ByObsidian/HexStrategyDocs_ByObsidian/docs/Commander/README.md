# Commander - ヘックス戦略ゲーム

## 概要
Commander は TypeScript/React で構築された第二次世界大戦をテーマとしたヘックス戦略ゲームです。プレイヤーは青軍として赤軍と戦い、地形を活用した戦術で都市を占領し、戦略的な勝利を目指します。最新版では天候システム、輸送・工作システム、UI/UX改善が大幅に強化されています。

## アーキテクチャ概要
- **技術スタック**: React 18.2.0, TypeScript 4.9.5
- **状態管理**: React Hooks ベース
- **ゲームフロー**: タイトル → ホーム → シナリオ選択 → 戦闘準備 → ユニット配置 → 戦闘 → 結果

## ゲームシステムの特徴

### 天候システム（🌦️ 最新実装）
- **4種類の天候**: 晴天、雨、大雨、嵐
- **視覚エフェクト**: リアルタイム雨滴アニメーション、稲妻効果
- **戦術的影響**: 移動コスト増加、視界制限、戦闘効率変化
- **背景変化**: 天候に応じた画面背景グラデーション

### 輸送システム（🚛 最新実装）
- **輸送ユニット**: 歩兵の高速移動支援
- **乗車・降車**: 戦術的な部隊展開
- **確認システム**: 意図しない操作を防ぐ降車確認モーダル
- **戦略価値**: 機動戦術の実現、補給線の効率化

### 工作システム（⚙️ 最新実装）
- **工作車**: 地形改変による戦術的優位性確保
- **架橋**: 河川を越えた新たな進軍ルート開拓
- **橋破壊**: 敵進軍ルートの戦略的遮断
- **資材管理**: 限定資源による計画的な地形改変

### 地形戦術システム
- **17種類の地形**: 平原、森林、山岳、河川、道路、橋梁、都市、泥濘、海洋、首都、飛行場、生垣地、雪原、砂漠、岩礁、要塞、港
- **兵種別移動制限**: 歩兵は全地形対応、車両は河川・山岳通行不可
- **戦闘修正**: 地形による攻撃・防御ボーナス（山岳+3防御+2攻撃、要塞+3防御+1攻撃など）
- **戦術的価値**: 高所からの攻撃優位性、要塞での防御戦術、道路での高速機動

### UI/UX改善（🎮 最新実装）
- **ショートカットキー**: Cmd+E（ターン終了）、Esc（キャンセル）等
- **確認モーダル**: 重要操作の事前確認による誤操作防止
- **情報表示**: ターン切替時の天候・戦況通知
- **アクセシビリティ**: キーボード操作、スクリーンリーダー対応

### 補給システム
- **都市補給**: 占領都市でのHP・燃料回復
- **燃料管理**: 移動による燃料消費と補給の戦略的重要性
- **戦略拠点**: 首都・港・飛行場の特別効果

### 武器システム
- **派閥別武装**: 青軍・赤軍それぞれ専用の武器体系
- **射程管理**: ユニット・武器ごとの攻撃射程
- **弾薬管理**: 武器ごとの弾薬制限
