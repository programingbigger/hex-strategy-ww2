# Utils and Helpers

This document provides an overview of the utility functions in `Commander/src/utils`.

## File Index

- `battleLogger.ts`: A debugging system for logging battle events.
- `logger.ts`: A file-based logging system for the browser environment, with tracking for transport and infantry operations.
- `map.ts`: Contains utility functions for working with the game map, such as converting coordinates, calculating distances, and finding paths.
- `mapLoader.ts`: Contains functions for loading map data from JSON files.
- `productionOrder.ts`: Manages the production order system for units.
- `reinforcements.ts`: Contains utility functions for the reinforcement system.
- `weapons.ts`: Contains utility functions for working with weapons, such as getting available weapons and calculating attack ranges.
