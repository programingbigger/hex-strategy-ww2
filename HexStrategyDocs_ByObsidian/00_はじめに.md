# Commander - ヘックス戦略ゲーム ドキュメント

## 概要
Commander は TypeScript/React で構築された第二次世界大戦をテーマとしたヘックス戦略ゲームです。
このドキュメントは、ゲームの仕様、技術的な実装、開発資料などをまとめたものです。

## アーキテクチャ概要
- **技術スタック**: React, TypeScript
- **状態管理**: React Hooks (`useState`, `useCallback`) と `immer` を組み合わせたカスタムフック (`useGameLogic`) による集中管理。
- **ゲームフロー**: タイトル → メインメニュー → シナリオ/チュートリアル選択 → 戦闘準備 → ユニット配置 → 戦闘 → 結果

## ドキュメント構成
このドキュメントは、以下のカテゴリに分かれています。

- **[01_プレイヤーガイド](./01_プレイヤーガイド)**
  - ゲームの基本的な遊び方、ルール、戦術ガイドなどを記載しています。
- **[02_ゲーム仕様](./02_ゲーム仕様)**
  - ゲームフロー、画面仕様、天候や輸送などの各種システム仕様を記載しています。
- **[03_技術仕様](./03_技術仕様)**
  - データスキーマ、コンポーネント、ゲームロジックなど、技術的な実装に関する詳細を記載しています。
- **[99_開発資料](./99_開発資料)**
  - 開発計画、UI改善案、タスクリストなどを記載しています。

## ゲームシステムの主な特徴
- **フックベースのロジック**: `useGameLogic` を中心に、戦闘、ターン管理、ユニット操作などのロジックがモジュール化されたカスタムフックに分割されています。
- **データ駆動**: ユニットの性能やコストは `armyOrganization.json`、マップ構成はシナリオごとのJSONファイルで定義されており、拡張性が高くなっています。
- **戦術的システム**: 天候、輸送、工兵、ZOC（支配領域）、補給など、多彩なシステムが戦術の幅を広げます。
