# Commander - ヘックス戦略ゲーム ドキュメント

## 概要
Commander は TypeScript/React で構築された第二次世界大戦をテーマとしたヘックス戦略ゲームです。
このドキュメントは、ゲームの仕様、技術的な実装、開発資料などをまとめたものです。

## アーキテクチャ概要
- **技術スタック**: React 18.2.0, TypeScript 4.9.5
- **状態管理**: React Hooks ベース
- **ゲームフロー**: タイトル → ホーム → シナリオ選択 → 戦闘準備 → ユニット配置 → 戦闘 → 結果

## ドキュメント構成
このドキュメントは、以下のカテゴリに分かれています。

- **[01_プレイヤーガイド](./01_プレイヤーガイド)**
  - ゲームの基本的な遊び方、ルール、戦術ガイドなどを記載しています。
- **[02_ゲーム仕様](./02_ゲーム仕様)**
  - ゲームフロー、画面仕様、天候や輸送などの各種システム仕様を記載しています。
- **[03_技術仕様](./03_技術仕様)**
  - データスキーマ、コンポーネント、ゲームロジックなど、技術的な実装に関する詳細を記載しています。
- **[99_開発資料](./99_開発資料)**
  - 開発計画、UI改善案、タスクリストなどを記載しています。

## ゲームシステムの主な特徴
- **天候システム**: 晴天、雨、嵐などの天候が戦況に影響を与えます。
- **輸送・工兵システム**: 輸送ユニットによる部隊の高速移動や、工兵による架橋・橋破壊が可能です。
- **地形戦術**: 17種類の地形が移動や戦闘に影響を与え、戦術の幅を広げます。
- **UI/UX**: キーボードショートカットや確認モーダルにより、快適な操作性を目指しています。
