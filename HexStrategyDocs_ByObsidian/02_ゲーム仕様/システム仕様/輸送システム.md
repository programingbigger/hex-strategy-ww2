# 輸送システム

## 概要

輸送ユニット（輸送車、輸送機など）は、他の地上ユニットを搭載し、迅速に長距離を移動させるためのシステムです。歩兵や火砲など、移動力の低いユニットの機動力を大幅に向上させ、戦術の幅を広げます。

---

## 輸送プロセス

輸送は「搭載（Load）」と「降車（Unload）」の2つのアクションで構成されます。

### 1. ユニットの搭載 (Load)

- **アクション主体**: 輸送されたいユニット（例: 歩兵、対戦車砲）。
- **実行条件**: 輸送されたいユニットが、味方の輸送ユニットに隣接している必要があります。
- **実行方法**:
    1. 搭載したいユニット（例: 歩兵）を選択します。
    2. `SelectedUnitPanel` に表示される「📦 搭載」ボタンを押します。
    3. ユニットは自動的に隣接する輸送ユニットに搭載され、マップ上から非表示になります。ユニットは行動終了状態になります。

### 2. ユニットの降車 (Unload)

- **アクション主体**: 輸送ユニット。
- **実行条件**: 輸送ユニットがユニットを1体以上搭載している必要があります。
- **実行方法**:
    1. ユニットを降ろしたい輸送ユニットを選択します。
    2. `SelectedUnitPanel` に表示される「📤 降車」ボタンを押します。
    3. **`UnitSelectionModal`** が表示され、搭載されているユニットの中から降ろしたいユニットを1体選択します。
    4. マップ上で降車可能なタイル（隣接する、ユニットがいない、進入可能な地形）がハイライトされます。
    5. 降車させたいタイルをクリックします。
    6. **`TransportActionConfirmModal`** で最終確認が行われ、「確認」を押すとユニットがそのタイルに配置されます。降ろされたユニットと輸送ユニットは行動終了状態になります。

---

## 輸送容量 (Transport Capacity)

輸送ユニットには、搭載可能なユニットの総量を示す「容量（Capacity）」が設定されています。また、搭載される各ユニットには、その容量をどれだけ消費するかを示す「コスト」が設定されています。

- **定義場所**: `/data/armyOrganization.json` 内の各輸送ユニットの定義。
- **例**:
    - 輸送車の容量が `2` の場合…
    - 歩兵（コスト`1`）を2体搭載可能。
    - 歩兵（コスト`1`）1体と対戦車砲（コスト`1`）1体を搭載可能。
    - 火砲（コスト`2`）を1体搭載可能。

```json:armyOrganization.json の輸送ユニット定義例
"transport": {
  "capacity": 2,
  "transportableUnits": ["infantry", "antitank", "artillery"],
  "unitCapacityCosts": {
    "infantry": 1,
    "antitank": 1,
    "artillery": 2
  }
}
```

## 搭載可能なユニット

輸送ユニットに搭載可能なユニットの種類は、輸送ユニット側の `transportableUnits` プロパティで定義されます。一般的には以下の通りです。

- 歩兵 (Infantry)
- 対戦車砲 (AntiTank)
- 火砲 (Artillery)

---

## 戦術的活用

- **迅速な部隊展開**: 歩兵や火砲などの移動力が低いユニットを前線へ素早く輸送する。
- **電撃作戦**: 敵の防御が手薄な側面や背後に、輸送ユニットを使って奇襲部隊を送り込む。
- **陣地転換**: 危険に晒された火砲や対戦車砲を、安全な後方や別の陣地へ迅速に移動させる。
- **河川の克服**: 橋がない川を渡れないユニットを、対岸まで輸送する（輸送ユニットが通行可能な場合）。
