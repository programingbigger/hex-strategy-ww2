# 戦闘システム

## 概要

戦闘は、マップ上で敵味方のユニットが接触した際に発生します。戦闘の結果は、ユニットの能力、地形効果、武器の相性など、様々な要因によって決定されます。戦闘は攻撃側と防御側のフェーズで構成され、反撃（Counter-Attack）が発生することもあります。

---

## 戦闘のプロセス

戦闘は以下の流れで処理されます (`battleSystem.ts` の `handleAttackWithWeapon` が主導)。

1.  **攻撃開始**: プレイヤーが攻撃可能な敵ユニットを選択し、使用する武器を決定すると戦闘が開始されます。
2.  **ダメージ計算**: 攻撃側が防御側に与えるダメージが計算されます。
3.  **防御側の損害適用**: 計算されたダメージが防御側ユニットのHPから引かれます。
4.  **反撃判定**: 防御側ユニットが反撃可能かどうかが判定されます。
    - 砲兵（Artillery）からの攻撃に対しては反撃できません。
    - 反撃可能な武器と弾薬を持っている必要があります。
5.  **反撃ダメージ計算**: 反撃可能な場合、防御側が攻撃側に与えるダメージが計算されます。
6.  **攻撃側の損害適用**: 反撃ダメージが攻撃側ユニットのHPから引かれます。
7.  **戦闘終了**: 両者のHPが更新され、HPが0以下になったユニットはマップから除去されます。戦闘結果はバトルログに記録されます。

---

## ダメージ計算式

ダメージは、以下の要素を元に算出されます。

**基本ダメージ = (武器の基本攻撃力 × 武器相性補正) + 地形攻撃ボーナス - (ユニットの防御力 + 地形防御ボーナス)**

- **最低保証ダメージ**: 計算結果が0以下になった場合でも、最低1ダメージは保証されます。

### 武器の基本攻撃力 (`Weapon.attack`)
各武器に設定されている基本的な攻撃力です。

### 武器相性補正 (`Weapon.effectiveness`)
武器には、特定のユニットクラスに対して高い効果を発揮する相性補正が設定されている場合があります。例えば、対戦車砲は `Vehicle` クラスに対して高いダメージを与えます。

```typescript:effectivenessの例
// 57mm対戦車砲のeffectivenessプロパティ
effectiveness: {
  Infantry: 0.8, // 歩兵に対しては威力が落ちる
  Vehicle: 1.5   // 車両に対しては威力が上がる
}
```

### 地形効果 (`TERRAIN_STATS`)
ユニットがいる地形によって、攻撃力や防御力にボーナスまたはペナルティが適用されます。

- **攻撃ボーナス**: 丘陵など、一部の地形で発生します。
- **防御ボーナス**: 森林、都市、要塞などの地形で発生します。防御側の地形ボーナスは、戦闘において非常に重要な要素となります。
- **砲兵の特性**: 砲兵（Artillery）が攻撃する場合、防御側の地形防御ボーナスは**無視**されます。

---

## 反撃 (Counter-Attack)

防御側ユニットは、攻撃を受けた後に特定の条件下で反撃を行うことができます。

- **反撃の条件**:
    1.  ユニットが `canCounterAttack: true` のプロパティを持っている。
    2.  攻撃が砲兵によるものではない。
    3.  攻撃してきた敵ユニットが、自身のいずれかの武器の射程内にいる。
    4.  射程内にいる敵を攻撃できる武器の弾薬が残っている。

- **反撃武器の選択 (`weapons.ts` - `selectCounterAttackWeapon`)**:
    - 反撃時に使用する武器は、最も効果が期待できるものが自動的に選択されます。
    - 例えば、戦車が対戦車兵器で攻撃された場合は主砲で反撃し、歩兵に攻撃された場合は機関銃で反撃する、といったロジックが組まれています。

---

## 武器と弾薬 (`Unit.weapons`)

各ユニットは複数の武器を持つことができ、それぞれに弾薬数が設定されています。

- **武器の選択**: 複数の武器で攻撃可能な場合、プレイヤーは攻撃時に使用する武器を選択します（`WeaponSelectorModal`）。
- **弾薬の消費**: 攻撃または反撃を行うと、使用した武器の弾薬 (`ammunition`) が1つ消費されます。
- **弾切れ**: 弾薬が0になると、その武器では攻撃できなくなります。
- **補給**: 都市や首都にいると、ターン開始時にすべての武器の弾薬が最大まで補充されます（経済システム参照）。
