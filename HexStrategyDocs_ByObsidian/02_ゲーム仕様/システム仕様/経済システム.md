# 経済システム

## 概要

このゲームにおける経済は、ユニットの生産、維持、そして特殊なアクションの実行を支える基盤です。プレイヤーは、所有する都市や首都から得られる収入を元に、軍事行動の計画を立てる必要があります。経済は主に「収入」と「支出」の2つの要素で構成されます。

---

## 収入 (Income)

収入は、自軍のターンが始まるごとに、所有している特定の建造物から自動的に得られます。

- **収入源**: `首都 (Capital)` および `都市 (City)`。
- **計算タイミング**: 各プレイヤーのターン開始時（例: 青軍のターンが始まる時）。
- **計算ロジック (`incomeManager.ts`)**:
    - 基本的に、各都市・首都には基本収入額が設定されています。
    - 建造物のHPが満タンに近いほど、より多くのボーナス収入が得られます。
    - 詳細な計算式や各建造物の収入額は `/public/data/settings/income_settings.json` ファイルで定義されています。

```json:income_settings.json (サンプル)
{
  "incomeSettings": {
    "Capital": {
      "baseIncome": 500,
      "hpIncomeMultiplier": 2 // HPが2回復するごとに収入が上乗せされる等
    },
    "City": {
      "baseIncome": 200,
      "hpIncomeMultiplier": 5
    }
  }
}
```

---

## 支出 (Expenditure)

支出は、主に「ユニット生産」「ユニットの補給」「工兵のアクション」の3つのカテゴリで発生します。

### 1. ユニット生産コスト

首都などの生産拠点で新しいユニットを生産する際に発生するコストです。

- **コスト決定要因**: ユニットの強さや種類によって、個別の生産コストが `armyOrganization.json` 内で定義されています。
- **支払い処理 (`productionCostManager.ts`)**:
    1. プレイヤーが生産したいユニットを選択します。
    2. `calculateProductionCost` が `armyOrganization.json` を参照し、必要なコストを取得します。
    3. `processSingleProductionRequest` がプレイヤーの保有資金とコストを比較し、支払いが可能であれば資金を差し引き、ユニットを生産キューに追加します。

### 2. ユニット補給コスト

都市や首都にいるユニットが、ターン開始時にHP、燃料、弾薬を回復・補充する際に発生するコストです。

- **コスト決定要因 (`costManager.ts`)**:
    - **HP回復**: 減少しているHPが多いほど高くなります。
    - **燃料補給**: 消費している燃料が多いほど高くなります。
    - **弾薬補充**: 消費している弾薬が多いほど高くなります。
- **特徴**: 補給は自動で行われますが、資金が不足している場合は、可能な範囲でのみ補給が行われるか、全く行われない場合があります。

### 3. 工兵アクションコスト

工兵ユニットが地形を変化させるなどの特殊なアクションを実行する際に発生するコストです。

- **コストの種類**: アクションには「資金コスト」と「資材コスト」の2種類があります。
    - **資金コスト**: プレイヤーの保有資金から支払われます。
    - **資材コスト**: 工兵ユニット自身が持つ「資材」リソース（武器の一種として扱われる）を消費します。
- **支払い処理 (`engineerActionCostManager.ts`)**:
    - `validateEngineerAction` が、アクション実行前に資金と資材の両方が足りているかを確認します。
    - `processEngineerActionWithCost` が、検証後に実際のコストを差し引きます。
- **コストの例**:
    - **架橋 (build_bridge)**: 資金: 75, 資材: 2
    - **要塞化 (build_fortress)**: 資金: 100, 資材: 1
    - **増築 (enhance_city)**: 資金: 50, 資材: 1
