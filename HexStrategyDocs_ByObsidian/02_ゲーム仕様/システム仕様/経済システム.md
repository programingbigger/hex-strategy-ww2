# 経済システム

## 概要

このゲームの経済は、ユニットの生産、補給、そして特殊アクションの実行を支える基盤です。経済活動は主に、各ターンの変わり目に自動的に処理されます。

---

## 経済関連の処理フロー

経済に関する処理は `useGameLogic/turnManagement.ts` の `handleEndTurn` 関数内で、以下の順序で実行されます。

1.  **収入の獲得 (Income Phase)**
    - 新しいラウンドが始まる際（`Blue`チームのターン開始時）、両チームの収入が計算され、それぞれの資金に加算されます。
2.  **補給コストの支払いと実行 (Supply Phase)**
    - ターンが回ってきたチームのユニットに対して、補給処理とコスト支払いが実行されます。

ユニットの生産や工兵のアクションは、プレイヤーが任意のタイミングで指示し、その場でコストが支払われます。

---

## 1. 収入 (Income)

収入は、新しいラウンドの開始時（`Blue`チームのターン開始時）に、所有している建造物から自動的に得られます。

- **収入源**: `首都 (Capital)` および `都市 (City)`。
- **計算ロジック (`utils/incomeManager.ts`)**:
    - `calculateIncome` が、チームごとに所有する都市と首都から収入を計算します。
    - 各建造物には基本収入額が設定されており、建造物のHPが高いほどボーナス収入が得られます。
    - 詳細な計算式は `/public/settings/income_settings.json` で定義されています。

```json:income_settings.json (抜粋)
{
  "incomeSettings": {
    "Capital": { "baseIncome": 500, "hpIncomeMultiplier": 2 },
    "City": { "baseIncome": 200, "hpIncomeMultiplier": 5 }
  }
}
```

---

## 2. 支出 (Expenditure)

支出は、主に「ユニットの補給」「ユニットの生産」「工兵のアクション」の3つのカテゴリで発生します。

### ユニット補給

補給拠点（自軍が所有する都市・首都）にいるユニットが、自軍ターン開始時に自動で受ける補給です。

- **対象**: HP、燃料、弾薬が最大でないユニット。
- **補給内容 (`turnManagement.ts` 内で処理)**:
    - HPが10回復 (最大HPを超えない)
    - 弾薬と燃料が最大まで回復
- **コスト**: 以前のバージョンではコストがかかっていましたが、**現在の実装では補給にコストはかかりません** (`supplyCostManager.ts` は現在使用されていません)。

### ユニット生産コスト

生産拠点（首都など）で新しいユニットを生産する際に発生するコストです。これはプレイヤーが生産を指示したタイミングで支払われます。

- **コスト計算 (`utils/productionCostManager.ts`)**:
    - `getCost` がユニットの基本コストを取得します。
- **支払い処理 (`hooks/useGameLogic/armyManagement.ts`)**:
    - `handleUnitProduction` が、生産時に資金が十分か検証し、コストを差し引きます。

### 工兵アクションコスト

工兵ユニットが「架橋」や「要塞化」などの特殊アクションを実行する際に発生するコストです。これもアクションを指示したタイミングで支払われます。

- **コストの種類**:
    - **資金コスト**: チームの資金から支払われます。
    - **資材コスト**: 工兵ユニット自身が持つ「資材」リソースを消費します。
- **支払い処理 (`hooks/useGameLogic/enhancedEngineerActions.ts`)**:
    - `handleEnhancedMaterialAction` が、`utils/engineerActionCostManager.ts` を利用して資金と資材の両方が足りているかを確認し、アクション実行時にコストを差し引きます。
