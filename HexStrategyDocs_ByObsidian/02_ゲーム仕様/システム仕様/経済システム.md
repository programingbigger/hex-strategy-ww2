# 経済システム

## 概要

このゲームの経済は、ユニットの生産、維持、そして特殊アクションの実行を支える基盤です。経済活動は主に、各ターンの開始時に行われる**経済フェーズ**で処理されます。このフェーズは `GameEconomyManager.ts` によって管理され、「収入」「支出」の2つの主要な要素で構成されます。

---

## 経済フェーズの処理フロー

`GameEconomyManager` は、ターン開始時に以下の順序で各チームの経済処理を自動的に実行します。

1.  **収入の獲得 (Income Phase)**
    - 所有する都市・首都から資金を徴収します。
2.  **補給コストの支払い (Supply Phase)**
    - 補給拠点にいるユニットのHP回復、燃料・弾薬の補充にかかるコストを支払います。
3.  **生産コストの支払い (Production Phase)**
    - プレイヤーが要求したユニットの生産コストを支払います。

これにより、ターン開始時の資金から補給と生産のコストが差し引かれ、そのターンの最終的な資金が確定します。

---

## 1. 収入 (Income)

収入は、自軍のターンが始まるごとに、所有している特定の建造物から自動的に得られます。

- **収入源**: `首都 (Capital)` および `都市 (City)`。
- **計算ロジック (`incomeManager.ts`)**:
    - 各都市・首都には基本収入額が設定されています。
    - 建造物のHPが高いほど、より多くのボーナス収入が得られます。
    - 詳細な計算式は `/public/data/settings/income_settings.json` で定義されています。

```json:income_settings.json (抜粋)
{
  "incomeSettings": {
    "Capital": { "baseIncome": 500, "hpIncomeMultiplier": 2 },
    "City": { "baseIncome": 200, "hpIncomeMultiplier": 5 }
  }
}
```

---

## 2. 支出 (Expenditure)

支出は、主に「ユニットの補給」「ユニットの生産」「工兵のアクション」の3つのカテゴリで発生します。

### ユニット補給コスト

補給拠点（自軍が所有する都市・首都）にいるユニットが、ターン開始時に自動で受ける補給にかかるコストです。

- **対象**: HP、燃料、弾薬が最大でないユニット。
- **コスト計算 (`supplyCostManager.ts`)**:
    - `calculateSupplyCost` が、回復・補充が必要な量に応じてコストを算出します。
    - 不足しているHP、燃料、弾薬が多いほどコストは高くなります。
- **支払い処理**: 
    - `applySupplyOperationsWithCost` が、チームの資金から総補給コストを差し引きます。
    - 資金が不足している場合、支払える範囲のユニットのみが補給されます（コストの安いユニットが優先）。

### ユニット生産コスト

生産拠点（首都など）で新しいユニットを生産する際に発生するコストです。

- **コスト定義**: ユニットごとの生産コストは `armyOrganization.json` で定義されています。
- **支払い処理 (`productionCostManager.ts`)**:
    - `validateProductionRequest` が、生産要求に必要な総コストを計算し、資金が十分か検証します。
    - `processProductionRequests` が、検証後に資金を差し引き、生産を実行します。

### 工兵アクションコスト

工兵ユニットが「架橋」や「要塞化」などの特殊アクションを実行する際に発生するコストです。これは経済フェーズとは別に、プレイヤーがアクションを指示したタイミングで支払われます。

- **コストの種類**: 
    - **資金コスト**: チームの資金から支払われます。
    - **資材コスト**: 工兵ユニット自身が持つ「資材」リソースを消費します。
- **支払い処理 (`engineerActionCostManager.ts`)**:
    - `validateEngineerAction` が、資金と資材の両方が足りているかを確認します。
    - `processEngineerActionWithCost` が、アクション実行時にコストを差し引きます。
