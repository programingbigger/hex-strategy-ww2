# 補給システム

## 概要

補給システムは、補給ユニット（補給馬車・補給トラック）が戦場で戦闘ユニットの弾薬や燃料を供給する仕組みです。
補給アクションは **Pull型** で、受給側のユニットが隣接する補給ユニットから自ら物資を引き出す方式です。

## 武装の詳細

### 補給物資 (Supply Kit)
- 攻撃武器ではない。`isSupplyKit: true` フラグで識別される。
- 弾薬数は0（消耗しない）。
- `getAttackableWeapons()` から除外され、攻撃対象にならない。

### 自衛用ライフル (Self-Defense Rifle)
- `canInitiateAttack: false` フラグを持つ。
- プレイヤーが能動的に攻撃対象を選ぶことはできない。
- **敵から攻撃された際の「反撃」でのみ使用される。**
- `selectCounterAttackWeapon()` では反撃武器として正常に選択される。

## 補給物資の回復（ターン開始時）

補給ユニットは自軍の都市または首都でターンを開始すると、補給物資が最大値まで回復します。

### 回復条件
以下の条件を**全て**満たすとき、ターン開始時に補給物資が回復する。

1. 補給ユニット（SupplyWagon または SupplyTruck）である
2. 自軍が所有する **City** または **Capital** 上に位置する
3. 現在の `supplyStock` が `maxSupplyStock` 未満である

### 回復量
- 条件を満たした場合、`supplyStock` は `maxSupplyStock` まで完全回復する

### 実装の詳細
`turnManagement.ts` の `applySupplyOperations()` 関数で、他のユニットの HP・燃料・弾薬回復と同時に処理される。

```typescript
// 補給ユニットの場合、supplyStock を最大値に回復
const unitIsSupplyType = isSupplyUnit(unit);
const needsSupplyRestock = unitIsSupplyType && 
  unit.supplyStock !== undefined && 
  unit.maxSupplyStock !== undefined && 
  unit.supplyStock < unit.maxSupplyStock;
const newSupplyStock = needsSupplyRestock ? unit.maxSupplyStock : unit.supplyStock;
```

## アクション仕様 (Pull型・フリーアクション)

### 発動条件
プレイヤーが任意のユニット（受給側）を選択した際、以下条件を全て満たす場合に「補給」コマンドが有効化される。

1. **距離**: 対象ユニットの隣接1ヘックス以内に補給ユニットが存在する。
2. **所属**: その補給ユニットが友軍である。
3. **在庫**: その補給ユニットの `supplyStock` が1以上である。
4. **需要**: 受給側ユニットの弾薬または燃料が最大値未満である。

> 補給ユニット自身は受給側にならない。

### 供給元の自動選択
- 隣接する補給ユニットが1体の場合: そのユニットを対象とする。
- 複数体の場合: `supplyStock` が最大のユニットを自動選択する。

### 回復量の計算
```
必要量 = (燃料不足分) + (弾薬不足分の合計)
供給可能量 = 供給元の supplyStock
実際の回復量 = Min(必要量, 供給可能量)
```

回復の分配順序は「燃料優先」で、残りを弾薬に充当する。弾薬は武器の順番に沿って埋める。

### ステータスの更新
- **受給側**: 燃料と弾薬が回復量に基づいて回復される。
- **供給側**: `supplyStock` が実際に供給した量だけ減算される。

### 行動権の扱い (フリーアクション)
補給アクションは **フリーアクション** として扱う。

- **受給側ユニット**: 補給を行っても `moved` や `attacked` に変化しない。
  - 例: [補給] -> [移動] -> [攻撃] が可能。
  - 例: [移動] -> [補給] -> [攻撃] も可能。
- **供給側ユニット**: 物資を提供しても行動終了にならない。

## UI表示

### 選択中ユニットパネル (SelectedUnitPanel)
補給ユニットを選択した際、パネル内に補給物資量のプログレスバーが表示される。

### 詳細スペックダイアログ (UnitDetailsDialog)
補給ユニットの詳細ダイアログでは、HP・燃料・弾薬の下に**補給物資量**が表示される。

| 表示項目 | 内容 |
|:---|:---|
| ラベル | 📦 補給物資 |
| プログレスバー | 現在の `supplyStock` / `maxSupplyStock` を視覚化 |
| 数値表示 | 例: `30/30` (補給馬車), `50/50` (補給トラック) |
| バーの色 | `--earth-info` (青系) |

```typescript
{(unit.type === 'SupplyWagon' || unit.type === 'SupplyTruck') && (
  <div className="info-item">
    <span className="info-label">📦 補給物資</span>
    <ProgressBar
      current={unit.supplyStock ?? 0}
      max={unit.maxSupplyStock ?? 1}
      color="var(--earth-info, #5b9bd5)"
    />
    <span className="info-value">{unit.supplyStock ?? 0}/{unit.maxSupplyStock ?? 0}</span>
  </div>
)}
```
