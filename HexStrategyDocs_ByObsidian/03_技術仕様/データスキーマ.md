# データスキーマ

このドキュメントは、ゲームで利用される主要なデータ構造と型定義について説明します。これらの定義は主に `/src/types/index.ts` に記述されています。

## 主要なデータ構造

### `GameState`

ゲーム全体の状態を保持する最も重要なインターフェースです。セーブデータやターン間の状態管理の基本となります。

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| `currentScreen` | `GameScreen` | 現在表示されているゲーム画面。 |
| `selectedMap` | `GameMap` | プレイヤーが選択したマップの情報。 |
| `units` | `Unit[]` | マップ上に存在する全ユニットの配列。 |
| `board` | `BoardLayout` | マップのタイル情報を保持するMapオブジェクト。 |
| `activeTeam` | `Team` | 現在行動中のチーム（BlueまたはRed）。 |
| `turn` | `number` | 現在のターン数。 |
| `winner` | `Team` | 勝者が決定した場合、そのチーム。 |
| `gameState` | `'playing' \| 'gameOver'` | ゲームの進行状態。 |
| `weather` | `WeatherType` | 現在の天候。 |
| `weatherDuration` | `number` | 天候が持続するターン数。 |
| `battlePrep` | `BattlePrepState` | 戦闘準備画面の状態。 |

### `Unit`

マップ上の個々のユニットを表すインターフェースです。ユニットの能力、状態、位置情報などが含まれます。

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| `id` | `string` | ユニットの一意なID。 |
| `type` | `UnitType` | ユニットの種別（歩兵、戦車など）。 |
| `team` | `Team` | 所属するチーム。 |
| `faction` | `Faction` | 所属する勢力（BlueまたはRed）。 |
| `branch` | `MilitaryBranch` | 所属する兵科（陸、海、空）。 |
| `category` | `UnitCategory` | ユニットのカテゴリ。 |
| `name` | `string` | ユニットの表示名。 |
| `hp` | `number` | 現在のHP。 |
| `maxHp` | `number` | 最大HP。 |
| `defense` | `number` | 防御力。 |
| `movement` | `number` | 移動力。 |
| `x` | `number` | マップ上のx座標。 |
| `y` | `number` | マップ上のy座標。 |
| `moved` | `boolean` | このターンに移動済みか。 |
| `attacked` | `boolean` | このターンに攻撃済みか。 |
| `unitClass` | `UnitClass` | ユニットのクラス（歩兵、車両など）。 |
| `fuel` | `number` | 現在の燃料。 |
| `maxFuel` | `number` | 最大燃料。 |
| `weapons` | `Weapon[]` | ユニットが装備する武器の配列。 |
| `loaded` | `boolean` | 輸送ユニットに搭載されているか。 |
| `transportId` | `string` | 搭載されている輸送ユニットのID。 |

### `Tile`

マップを構成する個々のヘックス（タイル）を表すインターフェースです。

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| `x` | `number` | マップ上のx座標。 |
| `y` | `number` | マップ上のy座標。 |
| `terrain` | `TerrainType` | このタイルの地形。 |
| `owner` | `Team` | このタイルを所有するチーム。 |
| `hp` | `number` | タイル上の施設（都市など）のHP。 |
| `maxHp` | `number` | 施設の最大HP。 |
| `order` | `number` | 生産キューの順序など。 |

### `Weapon`

ユニットが使用する武器を表すインターフェースです。

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| `id` | `string` | 武器の一意なID。 |
| `name` | `string` | 武器の名称。 |
| `type` | `WeaponType` | 武器の種別。 |
| `ammunition` | `number` | 現在の弾薬数。 |
| `maxAmmunition` | `number` | 最大弾薬数。 |
| `range` | `{ min: number; max: number }` | 射程（最小・最大）。 |
| `attack` | `number` | 攻撃力。 |
| `effectiveness` | `{ [key in UnitClass]?: number }` | 特定のユニットクラスに対する攻撃補正。 |

### `ArmyOrganization`

軍隊の編成情報を定義するインターフェースで、`armyOrganization.json`のスキーマです。

- **`metadata`**: バージョン情報などのメタデータ。
- **`factions`**: `Blue`と`Red`の勢力ごとの情報。
    - **`branches`**: 陸・海・空の兵科ごとの情報。
        - **`unitCategories`**: 歩兵、機甲などのカテゴリごとの情報。
            - **`units`**: 各ユニットの詳細なテンプレート (`ArmyUnitTemplate`) の配列。
- **`commandStructure`**: 指揮系統やボーナスに関する定義。

## 型定義 (Type Aliases and Enums)

### ゲーム進行関連

- **`GameScreen`**: `'title' | 'home' | 'scenario-select' | 'battle-prep' | 'deployment' | 'battle'`
- **`Team`**: `'Blue' | 'Red'`
- **`Faction`**: `'Blue' | 'Red'`
- **`VictoryCondition`**: `'unit_elimination' | 'capital_capture' | 'city_capture' | 'turn_limit' | 'custom'`

### ユニット関連

- **`MilitaryBranch`**: `'陸' | '海' | '空'`
- **`UnitCategory`**: `'infantry' | 'armor' | 'artillery' | 'antitank' | 'support' | 'destroyer' | 'cruiser' | 'battleship' | 'fighter' | 'bomber' | 'transport'`
- **`UnitType`**: `'Infantry' | 'Tank' | 'ArmoredCar' | 'Artillery' | 'AntiTank' | 'Engineer' | 'Transport'`
- **`UnitClass`**: `'Infantry' | 'Vehicle'`
- **`WeaponType`**: 武器の具体的な種別名（例: `'37mm主砲'`, `'50mm主砲'`など多数）。

### マップ・天候関連

- **`TerrainType`**: `'Plains' | 'Forest' | 'Mountain' | 'River' | 'Road' | 'Bridge' | 'City' | 'Mud' | 'Sea' | 'Capital' | 'Airport' | 'Bocage' | 'Snow' | 'Desert' | 'Reef' | 'Fortress' | 'Port'`
- **`WeatherType`**: `'Clear' | 'Rain' | 'Storm' | 'Cloudy'`

---

## その他の重要なインターフェース

- **`GameMap`**: マップ選択画面で表示されるマップの基本情報。
- **`BattleResult`**: 戦闘終了時のリザルト情報。
- **`BattleReport`**: 個々の戦闘結果の詳細レポート。
- **`MapData`**: マップファイル (`.json`) の全体構造。
- **`UnitCost`**: ユニットの生産コストや補給コスト。
- **`BattleLogEntry`**: UIに表示するための戦闘ログのエントリ。
