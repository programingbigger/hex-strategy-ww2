# データスキーマ

このドキュメントは、ゲームで利用される主要なデータ構造と型定義について説明します。これらの定義は主に `/src/types/index.ts` に記述されています。

---

## `GameState` - ゲーム全体の状態

ゲームのすべての状態を保持する最も重要なインターフェース。`useGameState`フックで管理されます。

| プロパティ | 型 | 説明 |
| :--- | :--- | :--- |
| `gameId` | `string` | ゲームセッションの一意なID。 |
| `status` | `'loading' \| 'playing' \| 'gameOver'` | ゲームの進行状態。 |
| `turn` | `number` | 現在のターン数。 |
| `activeTeam` | `Team` | 現在行動中のチーム (`'Blue' \| 'Red'`)。 |
| `boardLayout` | `BoardLayout` | マップのタイル情報を保持する `Map<string, Tile>`。 |
| `units` | `Unit[]` | マップ上に存在する全ユニットの配列。 |
| `weather` | `Weather` | 現在の天候情報 (`{ type: WeatherType; turnsLeft: number }`)。 |
| `armyFunds` | `{ [key in Team]: number }` | 各チームの保有資金。 |
| `history` | `GameState[]` | Undo機能のための状態スナップショット配列。 |
| `battleLogs` | `BattleLogEntry[]` | UIに表示するための戦闘ログの配列。 |
| `victor` | `Team \| null` | 勝者が決定した場合、そのチーム。 |
| `selectedUnitId` | `string \| null` | プレイヤーが選択中のユニットID。 |
| `selectedUnit` | `Unit \| null` | 選択中のユニットオブジェクト。 |
| `(highlighted/reachable/attackable)Tiles` | `Coordinate[]` | 各種ハイライト表示用のタイル座標配列。 |
| `show...Modal` | `boolean` | 各種モーダルウィンドウの表示状態フラグ。 |

---

## `Unit` - ユニット

マップ上の個々のユニットを表すインターフェース。

| プロパティ | 型 | 説明 |
| :--- | :--- | :--- |
| `id` | `string` | ユニットの一意なID。 |
| `type` | `UnitType` | ユニットの種別 (`'Infantry'`, `'Tank'`など)。 |
| `team` | `Team` | 所属するチーム。 |
| `name` | `string` | ユニットの表示名。 |
| `hp` / `maxHp` | `number` | 現在/最大HP。 |
| `defense` | `number` | 防御力。 |
| `movement` | `number` | 移動力。 |
| `x`, `y` | `number` | マップ上の座標。 |
| `moved`, `attacked` | `boolean` | このターンに行動済みかを示すフラグ。 |
| `unitClass` | `UnitClass` | ユニットのクラス (`'Infantry'` or `'Vehicle'`)。 |
| `fuel` / `maxFuel` | `number` | 現在/最大燃料。 |
| `weapons` | `Weapon[]` | ユニットが装備する武器の配列。 |
| `transporting` | `Unit[]` | (輸送ユニットの場合) 搭載しているユニットの配列。 |
| `transportCapacity`| `number` | (輸送ユニットの場合) 搭載可能な最大ユニット数。 |
| `supplyStock` | `number?` | (補給ユニットの場合) 現在の補給物資量。 |
| `maxSupplyStock` | `number?` | (補給ユニットの場合) 最大補給物資量。 |

---

## `ArmyUnitTemplate` - ユニットテンプレート

`armyOrganization.json` で定義される、ユニットの完全な設計図。新しいユニットを生成する際の基盤となります。

| プロパティ | 型 | 説明 |
| :--- | :--- | :--- |
| `id` | `string` | テンプレートの一意なID（例: `'SupplyWagon'`）。 |
| `name` | `string` | ユニットの表示名。 |
| `type` | `UnitType` | ユニットの種別。 |
| `faction` | `Faction` | 所属勢力（`'Axis'` or `'Allies'`）。 |
| `branch` | `MilitaryBranch` | 軍種（`'Army'`, `'Navy'`, `'AirForce'`）。 |
| `category` | `UnitCategory` | ユニットカテゴリ（`'Infantry'`, `'Armor'`, `'Support'`など）。 |
| `stats` | `UnitStats` | HP、防御、移動力などの基本ステータス。 |
| `weapons` | `Weapon[]` | 装備する武器の配列。 |
| `cost` | `UnitCost` | 生産コスト。 |
| `supply?` | `{ maxSupplyStock: number }` | (補給ユニットの場合) 補給物資の最大保持量。 |

### 補給ユニットの `supply` プロパティ

補給ユニット（`SupplyWagon`, `SupplyTruck`）には `supply` プロパティが定義されています。

```typescript
// ArmyUnitTemplate の supply プロパティ
supply?: {
  maxSupplyStock: number;  // 補給馬車: 30, 補給トラック: 50
};
```

このプロパティは `createUnit()` 関数でユニット生成時に参照され、`Unit` オブジェクトの `supplyStock` と `maxSupplyStock` に展開されます。

## `Tile` - タイル

マップを構成する個々のヘックス（タイル）を表すインターフェース。

| プロパティ | 型 | 説明 |
| :--- | :--- | :--- |
| `x`, `y` | `number` | マップ上の座標。 |
| `terrain` | `TerrainType` | このタイルの地形 (`'Plains'`, `'Forest'`など)。 |
| `owner` | `Team` | このタイルを所有するチーム。 |
| `hp` / `maxHp` | `number` | タイル上の施設（都市など）の現在/最大HP。 |

---

## `Weapon` - 武器

ユニットが使用する武器を表すインターフェース。

| プロパティ | 型 | 説明 |
| :--- | :--- | :--- |
| `id`, `name` | `string` | 武器の一意なIDと名称。 |
| `type` | `WeaponType` | 武器の種別 (`'37mm主砲'`など)。 |
| `ammo` / `maxAmmo` | `number` | 現在/最大弾薬数。 |
| `range` | `{ min: number; max: number }` | 射程（最小・最大）。 |
| `power` | `number` | 攻撃力。 |
| `effectiveness` | `{ [key in UnitClass]?: number }` | 特定のユニットクラスに対する攻撃補正。 |
| `canInitiateAttack` | `boolean?` | `false` の場合、プレイヤーによる能動的攻撃不可。反撃でのみ使用される（例：自衛用ライフル）。 |
| `isSupplyKit` | `boolean?` | `true` の場合、攻撃武器ではなく補給キットとして扱われる。 |

---

## `Reinforcement` - 増援

特定のターンに出現する増援部隊の情報を定義します。 (`/src/types/reinforcements.ts`)

| プロパティ | 型 | 説明 |
| :--- | :--- | :--- |
| `turn` | `number` | 増援が出現するターン。 |
| `team` | `Team` | 増援が所属するチーム。 |
| `unitId` | `string` | 出現するユニットのテンプレートID。 |
| `x`, `y` | `number` | 出現する座標。 |

---

## その他の主要な型定義

- **`Team`**: `'Blue' | 'Red'`
- **`UnitType`**: `'Infantry' | 'Tank' | 'ArmoredCar' | 'Artillery' | 'AntiTank' | 'Engineer' | 'Transport' | 'SupplyWagon' | 'SupplyTruck'`
- **`UnitClass`**: `'Infantry' | 'Vehicle'`
- **`TerrainType`**: `'Plains' | 'Forest' | 'Mountain' | 'River' | 'Road' | 'Bridge' | 'City' | 'Mud' | 'Sea' | 'Capital' | 'Airport' | 'Bocage' | 'Snow' | 'Desert' | 'Reef' | 'Fortress' | 'Port' | 'FrozenSea' | 'FrozenRiver'`（`FrozenSea`と`FrozenRiver`は吹雪時に動的に生成される凍結地形）
- **`WeatherType`**: `'Clear' | 'Rain' | 'Storm' | 'Cloudy' | 'Snow' | 'Blizzard' | 'Fog'`
- **`BattleLogEntry`**: UIに表示するための戦闘ログのエントリ構造。
