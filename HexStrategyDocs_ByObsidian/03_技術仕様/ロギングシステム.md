# ロギングシステム

## 概要

このプロジェクトでは、目的の異なる2つのロギングシステムが実装されています。

1.  **`logger.ts` (`FileLogger`)**: ゲームプレイ中の重要なイベント（輸送、歩兵の行動など）を記録し、ファイルとしてダウンロード可能な永続的ロガー。
2.  **`battleLogger.ts` (`BattleLogDebugger`)**: 開発中のリアルタイムデバッグを目的とした、コンソール出力用の高機能ロガー。

---

## 1. `logger.ts` (`FileLogger`)

`FileLogger`は、ゲームの進行状況や特定のユニットの行動を追跡・分析するために設計されたシステムです。

### 主な機能

- **イベントの記録**: ユニットの移動、輸送、歩兵のアクションなど、ゲーム内の主要なイベントをタイムスタンプ付きで記録します。
- **永続化**: 記録されたログはブラウザの `localStorage` に自動的に保存され、ページをリロードしても失われません。
- **ログのダウンロード**: 記録されたログを `.txt` ファイルとしていつでもダウンロードできます。特定のイベント（輸送や歩兵の行動のみ）に絞ってダウンロードすることも可能です。
- **多彩なログレベル**: `log`, `info`, `warn`, `error` といった標準的なログレベルに加え、`transport`, `infantry`, `unit_movement` といったカスタムレベルを持ちます。

### 主要な関数

- **`log(message, ...data)`**: 標準的なログを記録します。
- **`logTransportOperation(operation)`**: ユニットの搭載・降車イベントを専門に記録します。
- **`logInfantryAction(action)`**: 歩兵の移動、攻撃、占領などの行動を記録します。
- **`logUnitMovement(movement)`**: ユニットの移動経路や消費燃料などを記録します。
- **`downloadLogs()`**: すべてのログをダウンロードします。
- **`downloadTransportInfantryLogs()`**: 輸送と歩兵に関連するログのみをダウンロードします。
- **`clearLogs()`**: 記録されたすべてのログを消去します。

### シングルトンインスタンス

`logger.ts` は `fileLogger` というシングルトンインスタンスをエクスポートしており、アプリケーション全体で同じロガーを参照できます。

```typescript
import { log, logTransportOperation } from './utils/logger';

log('ゲーム開始');
logTransportOperation({ ... });
```

## 2. `battleLogger.ts` (`BattleLogDebugger`)

`BattleLogDebugger`は、開発者がリアルタイムで戦闘やシステムの内部状態を把握するために設計された、視覚的で直感的なデバッグ用ロガーです。

### 主な機能

- **絵文字付きログレベル**: ログの重要度や種類を絵文字で直感的に示します。
    - `BATTLE` (⚔️): 戦闘関連のログ
    - `INFO` (🔍): 一般的な情報
    - `WARN` (⚠️): 警告
    - `ERROR` (❌): エラー
    - `DEBUG` (🐛): 詳細なデバッグ情報
- **グループ化されたコンソール出力**: 関連データを持つログは、コンソールのグループ機能を使ってきれいに整形・表示されます。
- **ログの管理**: ログの取得、フィルタリング、クリア、統計情報の表示が可能です。
- **メモリ管理**: ログの最大保存件数が設定されており、メモリの肥大化を防ぎます。

### 主要な関数

- **`logBattle(message, data)`**: 戦闘イベントを記録します。
- **`logInfo(category, message, data)`**: カテゴリ分類された情報ログを記録します。
- **`logWarn(category, message, data)`: 警告ログを記録します。**
- **`logError(category, message, data)`**: エラーログを記録します。
- **`logDebug(category, message, data)`**: デバッグログを記録します。
- **`getLogs(level)`**: 指定されたレベルのログを取得します。
- **`clear()`**: すべてのログをクリアします。

### シングルトンインスタンス

`battleLogger.ts` も `battleLogDebugger` というシングルトンインスタンスと、そのヘルパー関数をエクスポートしています。

```typescript
import { logBattle, logInfo } from './utils/battleLogger';

logBattle('攻撃開始', { attacker: 'A', defender: 'B' });
logInfo('AI', '思考ルーチンを開始');
```
