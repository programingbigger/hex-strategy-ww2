# ロギングシステム

## 概要

このプロジェクトでは、目的の異なる2つのロギングシステムが実装されています。

1.  **`logger.ts`**: 開発中のデバッグを目的とした、コンソール出力用の汎用ロガー。
2.  **`battleLogger.ts`**: UIに表示するための、構造化された戦闘ログ (`BattleLogEntry`) を生成するユーティリティ。

---

## 1. `logger.ts` (汎用デバッグロガー)

`logger.ts` は、開発者がリアルタイムでアプリケーションの動作を確認するための、シンプルなコンソールロガーです。

### 主な機能

- **ログレベル**: `log`, `info`, `warn`, `error` の4つのレベルでログを出力します。
- **タイムスタンプ**: すべてのログメッセージには、`[HH:mm:ss]` 形式のタイムスタンプが自動的に付与されます。
- **シングルトンインスタンス**: `logger` というシングルトンインスタンスをエクスポートしており、アプリケーションのどこからでも同じロガーを呼び出せます。

### 使用方法

```typescript
import logger from './utils/logger';

logger.log('ゲーム開始');
// Console output: [14:32:10] ゲーム開始

logger.warn('資金が不足しています');
// Console output: [14:32:11] ⚠️ 資金が不足しています
```

*（注: 以前のバージョンにあったファイル保存やダウンロード機能は、現在の実装では削除されています。）*

---

## 2. `battleLogger.ts` (戦闘ログジェネレーター)

`battleLogger.ts` は、戦闘の結果をUI（`BattleLogPanel`など）に表示するために、構造化されたデータオブジェクト (`BattleLogEntry`) を生成する責務を持ちます。

### 主な機能

- **ログオブジェクトの生成**: `createBattleLogEntry` 関数が、攻撃側・防御側ユニット、使用武器、与えたダメージなどの情報を受け取り、`BattleLogEntry` 型のオブジェクトを生成して返します。
- **状態管理への統合**: このユーティリティ自体はログを保存しません。生成されたログオブジェクトは、`useGameState` フックの `addBattleLogEntry` 関数に渡され、`gameState` 内の `battleLogs` 配列に保存されます。

### 主要な関数

- **`createBattleLogEntry(turn, attacker, defender, weapon, damage, isCounterAttack)`**: 戦闘イベントの主要な情報から、`BattleLogEntry` オブジェクトを組み立てます。

### 実行プロセス

1.  `battleSystem.ts` で戦闘（攻撃や反撃）が発生します。
2.  `createBattleLogEntry` が呼び出され、戦闘結果をまとめたログオブジェクトが生成されます。
3.  `battleSystem.ts` が `addLogEntry`（実体は`useGameState`の`addBattleLogEntry`）を呼び出し、生成されたログオブジェクトを `gameState` に渡します。
4.  `gameState` が更新され、UIコンポーネントが新しい戦闘ログを検知して画面に表示します。
